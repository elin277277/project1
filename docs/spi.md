# SPI 和 BMI088 笔记

## SPI 是咋回事

SPI 一般用四根线：SCK（时钟）、MOSI（主发从收）、MISO（从发主收）、CS（片选）。它是全双工的——每个时钟沿同时进一位出一位。所以就算只想"读"，也得往外发点占位字节（dummy）来产生时钟，不然从机没法把数据送出来。

SPI 没有设备地址、也没有 ACK 这回事。主机想和哪个从机说话，就把哪个的 CS 拉低。所以读到了字节不代表读对了设备，要自己校验一下芯片 ID 才放心。

还有 CPOL（空闲时时钟是高还是低）和 CPHA（在第几个边沿采样），主机从机必须设成一样的，不然数据全是错的。这两个合起来就是所谓的 Mode 0/1/2/3。

## 这块板子上的配置

- 用 SPI1：SCK PB3、MISO PB4、MOSI PA7（板上就是这么布的线）。
- 8 位、高位先发、Mode 0（CPOL=0、CPHA=0）、软件控制 CS。
- 时钟分频到 2.625 MHz，比 BMI088 的上限 10 MHz 低，稳妥。
- 加速度计 CS 是 PA4，陀螺仪 CS 是 PB0，平时都拉高，要读谁就把谁拉低，一次只能拉低一个。

## 容易踩的坑

- 加速度计刚上电或复位后，要先随便读一次让它切到 SPI 模式，这次读的数据扔掉别用。
- 之后每次读加速度计，地址字节后面还会多出一个没用的 dummy 字节，要丢掉；陀螺仪没有这个。
- 比如读加速度 X/Y/Z：CS 拉低后连续发 `0x12|0x80`、一个 dummy、再六个占位字节，最后六个才是真数据。整个过程 CS 一直保持低，不能每个字节都切一次 CS。
- 写寄存器是 `reg & 0x7f` 再跟上数据。复位之后要等一下再读，然后核对 ID（加速度计 0x1e、陀螺仪 0x0f）。
- 加速度是小端有符号 16 位，±6g 量程下比例是 `6*9.80665/32768` m/s² 每格；陀螺 ±2000°/s 时比例 `2000*pi/180/32768` rad/s 每格；温度是带符号 11 位，`23 + raw*0.125` °C，别当成普通 16 位。

## 上板验证的顺序

先确认 CS 空闲时是高、SCK 波形正常 → 读两个 ID → 回读配置 → 静止时加速度模长差不多是 1g、转动时陀螺符号合理 → 拔掉线或 ID 错了要报错，不能把上一帧旧数据当成新的发出去。
