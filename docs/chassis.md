# 底盘运动学学习笔记

本文是作业推导与自检说明，不是上车调试记录。假设刚性平面底盘、轮子接地，驱动约束方向无滑移；忽略轮胎变形与辊子损耗。运动学只给速度目标，不能保证实际速度、牵引力或功率。

## 1. 先统一坐标与单位

车体系原点取底盘中心：`+x` 向前，`+y` 向左，`+z` 向上；俯视逆时针角速度 `ω > 0`。车体速度为 `(vx, vy, ω)`，分别用 m/s、m/s、rad/s。轮序固定为 **FL、FR、RL、RR**，半轴距 `a > 0`、半轮距 `b > 0` 均用 m：

| 轮位 | 坐标 `(x_i, y_i)` |
| --- | --- |
| FL 左前 | `(a, b)` |
| FR 右前 | `(a, -b)` |
| RL 左后 | `(-a, b)` |
| RR 右后 | `(-a, -b)` |

刚体上轮心的速度等于中心平移速度加转动速度：

```text
v_i = (vx, vy) + (0, 0, ω) × (x_i, y_i, 0)
    = (vx - ω y_i, vy + ω x_i)

FL: (vx - ωb, vy + ωa)    FR: (vx + ωb, vy + ωa)
RL: (vx - ωb, vy - ωa)    RR: (vx + ωb, vy - ωa)
```

这一步三类底盘通用，区别在轮子的接触约束。输入若来自场地坐标，应先用车身航向 `ψ` 转换：`vx = cosψ·Vx + sinψ·Vy`、`vy = -sinψ·Vx + cosψ·Vy`；不能把场地速度直接代入车体系矩阵。

## 2. 麦克纳姆轮：从被动方向消元

采用 45° 辊子 **X 配置**，具体符号以以下接地约束为准，不能只凭示意图的 X/O 名称套公式。各轮主轮平面沿 x；定义 `u_i = r_i·φ̇_i` 为主轮带符号圆周线速度，正转对应向前驱动，而非电机接线的正负。

辊子允许接触点沿某一地面方向被动滚动；**被动方向与接地辊子的轴线垂直，不是沿轴线滑动**。用单位向量 `p_i` 表示被动方向，`n_i` 表示其垂直约束方向（正负选向不影响约束）：

| 轮位 | 被动方向 `p_i` | 约束方向 `n_i` | 消去辊子速度后的约束 |
| --- | --- | --- | --- |
| FL、RR | `(1, 1)/√2` | `(1, -1)/√2` | `v_ix - v_iy = u_i` |
| FR、RL | `(1, -1)/√2` | `(1, 1)/√2` | `v_ix + v_iy = u_i` |

推导：主轮旋转的接地点速度为 `-u_i e_x`，辊子转动提供任意标量倍的 `p_i`。无滑移要求 `v_i - u_i e_x + λ_i p_i = 0`，两边点乘 `n_i` 消去 `λ_i`：

```text
n_i · (v_i - u_i e_x) = 0
u_i = (n_i · v_i) / (n_i · e_x)
```

因此这里不能直接把 `n_i·v_i` 当主轮线速度，否则会误差一个 `√2`。例如左前轮：`u_FL = (vx - ωb) - (vy + ωa) = vx - vy - (a+b)ω`。四轮合并得到：

```text
[ u_FL ]   [ 1  -1  -(a+b) ] [ vx ]
[ u_FR ] = [ 1   1   (a+b) ] [ vy ]
[ u_RL ]   [ 1   1  -(a+b) ] [ ω  ]
[ u_RR ]   [ 1  -1   (a+b) ]
```

令 `L = a+b`，分别输入正的 `V`、`Ω`，做三个基向量自检（“z”指绕 z 转动，不是竖直平移）：

| 输入 | `[u_FL, u_FR, u_RL, u_RR]` | 物理检查 |
| --- | --- | --- |
| `(V, 0, 0)` | `[V, V, V, V]` | 全部向前驱动 |
| `(0, V, 0)` | `[-V, V, V, -V]` | 同对角同号，向左平移 |
| `(0, 0, Ω)` | `[-LΩ, LΩ, -LΩ, LΩ]` | 左侧后退、右侧前进，逆时针 |

反向自检公式为 `vx=(FL+FR+RL+RR)/4`、`vy=(-FL+FR+RL-RR)/4`、`ω=(-FL+FR-RL+RR)/(4L)`，此处轮位缩写代表对应 `u`。四轮速度并非可任意独立指定：理想一致性条件为 `FL+FR=RL+RR`；不满足时会有滑移或测量残差。

推导思路可对照 [Modern Robotics §13.2](<https://modernrobotics.northwestern.edu/nu-gm-book-resource/13-2-omnidirectional-wheeled-mobile-robots-part-1-of-2/>)；轮序和前/左坐标约定可对照 [WPILib Mecanum](<https://docs.wpilib.org/en/stable/docs/software/kinematics-and-odometry/mecanum-drive-kinematics.html>)。引用中的角速度、线速度排列不一定相同，比较矩阵前应先重排。

## 3. 全向轮：沿驱动切向投影

对第 i 个全向轮，驱动单位方向取 `t_i=(cosα_i, sinα_i)`，`α_i` 从 +x 逆时针计。辊子允许沿 `p_i=(-sinα_i, cosα_i)` 被动运动，故 `v_i = u_i t_i + λ_i p_i`。点乘 `t_i` 得：

```text
u_i = t_i · (vx - ω y_i, vy + ω x_i)
    = cosα_i vx + sinα_i vy + (-y_i cosα_i + x_i sinα_i)ω
```

这里 `u_i` 就是轮的圆周线速度；与麦轮相比，被动方向恰与驱动方向垂直，不需要额外投影分母。一般布置必须检查组装后的速度矩阵秩为 3，轮数达到 3 并不自动意味着全向可控。

**四轮切向布置例子：** 取正方形 `a=b=h`、中心到轮心距离 `R=√2h`；各轮正方向统一沿绕中心逆时针的切向 `t_i=(-y_i, x_i)/R`：

| 轮位 | `α_i` | `t_i` |
| --- | --- | --- |
| FL | `3π/4` | `(-1, 1)/√2` |
| FR | `π/4` | `(1, 1)/√2` |
| RL | `-3π/4` | `(-1, -1)/√2` |
| RR | `-π/4` | `(1, -1)/√2` |

```text
k = 1/√2
[ u_FL ]   [ -k   k   R ] [ vx ]
[ u_FR ] = [  k   k   R ] [ vy ]
[ u_RL ]   [ -k  -k   R ] [ ω  ]
[ u_RR ]   [  k  -k   R ]
```

正向纯 x、纯 y、纯旋转的符号分别为 `[-,+,-,+]`、`[+,+,-,-]`、`[+,+,+,+]`；纯旋转时全部为 `RΩ`。这里的电机正向定义不同于麦轮，不能直接比较两张符号表。

对非正方形也可以取 `R_i=hypot(x_i,y_i)`、`t_i=(-y_i,x_i)/R_i`，旋转系数仍为 `R_i`，但安装角通常不再是 45°。切向的几何法向是径向，恰为辊子的被动方向；**不能加上“径向速度必须为零”的普通轮无侧滑约束**，否则会错误禁止平移。也不能令驱动方向沿径向却仍声称旋转系数为 `R_i`：径向驱动的该系数实际为零。

## 4. 舵轮：轮心速度决定朝向与轮速

舵轮通过主动转向，使普通轮滚动方向与轮心目标速度一致：

```text
q_ix = vx - ω y_i
q_iy = vy + ω x_i
s_i  = hypot(q_ix, q_iy)          # m/s，初始非负
θ_i  = atan2(q_iy, q_ix)          # rad，从 +x 逆时针计
```

- 正常运行中若 `s_i < ε`，将驱动速度设为零并保持上次有效目标朝向，避免对 `atan2(0,0)` 赋予物理意义。初次启用应以可信的当前角度初始化；角度反馈异常时禁止驱动，不能用“保持朝向”替代故障处理。
- 令 `δ = wrapToPi(θ_i - θ_measured)`。若 `|δ| > π/2`，取 `θ_i ← wrapToPi(θ_i+π)`、`s_i ← -s_i`；同一速度向量由更短的转向实现。连续角控制器还应选取离当前角最近的等价目标，不能在 ±π 边界绕远路。
- 纯向前：全部 `θ=0`；纯向左：全部 `θ=π/2`。纯逆时针时速度向量分别为 `(-bΩ,aΩ)`、`(bΩ,aΩ)`、`(-bΩ,-aΩ)`、`(bΩ,-aΩ)`，均与对应半径垂直；正方形的原始朝向恰与上一节表格相同。

这些是理想瞬时目标。舵向尚未到位时需要限制驱动，且转向速度、加速度和编码器零位需另行处理。参见 [WPILib Swerve 与最短转向优化](<https://docs.wpilib.org/en/stable/docs/software/kinematics-and-odometry/swerve-drive-kinematics.html>)。

## 5. 统一限幅与电机单位换算

不能逐轮硬截断后仍宣称保持了目标运动方向。对所有轮的带符号速度 `w_i`（麦轮/全向轮用 `u_i`，舵轮用 `s_i`），求同一缩放因子：

```text
κ = min(1, min_i(w_max_i / |w_i|))  # 只对非零 w_i 取比值
w_i ← κ w_i                       # 全零时 κ=1；舵轮朝向不变
```

在线性、理想约束下，这等价于统一缩放 `(vx,vy,ω)`，保留轮速比例；不等同于功率限制。还需独立考虑加速度、驱动器电流和供电限制。

轮半径 `r_i` 用 m，减速比定义为 `g_i=|电机转速/轮轴转速|`，例如减速器通常 `g_i>1`。电机安装方向记为 `σ_i∈{+1,-1}`：

```text
轮轴角速度(rad/s) = w_i / r_i
轮轴转速(rpm)    = 60 w_i / (2π r_i)
电机转子(rpm)    = σ_i g_i · 60 w_i / (2π r_i)
w_i(m/s)         = σ_i · 电机转子(rpm) · 2π r_i / (60 g_i)
```

转向减速比与驱动减速比应分开。电机反馈可能是转子 rpm、输出轴速度或原始计数，必须查具体协议；不能把原始电流计数直接当 A，也不能默认所有电机与 M2006/C610 兼容。

## 6. 可选：功率模型辨识思路

单电机驱动支路可尝试经验模型 `P≈a_P Iω_m+b_P I²+c_P ω_m²+d_P`，系数下标用于区别底盘尺寸 `a,b`。其中 `P=V_bus I_bus` 为支路电输入功率（W），`I` 为校准后的转矩相关电流（A，非母线电流），`ω_m` 为带符号电机转速（rad/s）。`Iω_m` 近似机械功率项，`I²` 表示铜耗趋势，`ω_m²` 和常数项只作经验损耗近似。

同步采样构造每行 `X_j=[I_jω_mj, I_j², ω_mj², 1]`，用 QR/SVD 最小化 `||Xβ-P||²`，再用未参与拟合的数据检验残差。需在安全限流下覆盖多种转速、负载和正反转，检查满秩与条件数；仅空载匀速数据通常不足以区分系数。整车总功率不能与单电机电流直接拟合，需按支路测量或求和建模并计入其他负载。

电流定义、温升、同步误差、加速过程储能与传动效率都会影响模型。再生制动可使电输入功率为负，且受驱动器与电池回馈能力限制；不能把负值一律当测量错误，也不能把驱动区拟合结果外推为全工况保护依据。此处未采集数据、未给出拟合参数或实测精度。
